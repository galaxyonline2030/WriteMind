# 模式卡写作模板

每个簇产一张卡，文件名 `NN_<模式名>.md`（NN = 簇号两位数）。子代理只读该簇 `_cluster_XX.json`。

## 模板

```markdown
# NN_<模式名>

> 签名 P?T?S? ｜ 规模 N 场景（来源：书A 1200 / 书B 36）｜ 一句话 essence：……

## 模式特征
- 结构：轮数节奏、切换快慢、说话人构成
- 技法：本簇最突出的 1–2 个对话技法（例如：截断半句靠内心回指补潜台词）

## 真实对白示例（引自簇样本 excerpt，保留原句）
> 「……」（<角色>，《<书名>》）

## 反模式（生成后的自检清单）
- ❌ ……（本簇场景里原作不会出现的写法，如：AI 常把潜台词直说破）

## 临摹要点
- 1) ……
- 2) ……

## 允许的不完美（人类毛刺，非缺陷）
- 口误、被打断、思路跳变、不完美回应是真实对白的自然纹理，临摹时保留，不要一律修平。
```

## 写作要求

1. **essence 必须一句话**，落在"读者感受"上（如：短回合传球式质询 + 留白中推进群像推理）。
2. **对白示例必须摘自簇文件 excerpt 原句**，注明角色与来源；禁止凭印象编写示例。
3. **反模式**来自跨样本共性观察（≥3 个样本都规避的写法才入列）。
4. 簇规模 ≤6 时，在卡头加注：`样本偏小，与相邻簇 XX 有重叠，作补充参考`。
5. 卡文件命名与簇号绑定；若场景级重聚类导致签名重排，须核对旧卡归属后再复用或重写。

## 示例（节选自真实产物）

```markdown
# 05_双人静默对峙

> 签名 P1T1S1 ｜ 规模 14 场景 ｜ 一句话 essence：张力不靠喊叫，把威胁说半句、
> 用"……"和沉默在两人之间发酵

## 模式特征
- 结构：≤6 轮、切换率 <0.5，双方各自连占短轮
- 技法：威胁压成平铺直叙的结论；"……"承担对峙的呼吸
```
